# 固定費まるみえシート

毎月の固定費と手作業のコストを見える化し、AI活用でどれくらい抑えられそうかを試算する簡易ツールです。

## 使い方（Windows / Mac / スマホ 共通）

- **URLで受け取った場合**: ブラウザで開くだけです。インストールは不要です。
- **ファイルで受け取った場合**: `index.html` をダブルクリックすると、ブラウザで開きます。
  - Windows: Microsoft Edge / Google Chrome
  - Mac: Safari / Google Chrome
  - プログラムのインストールや、Python などの準備は一切不要です。

## 動作要件

- Windows 10 以降 / 最新の macOS / iOS・Android の最近のブラウザ
- インターネット接続は、ページを開くときだけ必要です（ファイルで開く場合は不要）

## データの扱い

入力した内容は、お使いの端末のブラウザの中だけに保存されます。外部には送信されません。
ブラウザの閲覧データを消去すると、入力内容も消えます。

## 診断結果について

「AI活用診断」の金額は、項目ごとに削減割合を仮定して計算した目安です。
実際の効果は、業務の内容や利用中のサービスによって変わります。
